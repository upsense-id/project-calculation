# UPSENSE Estimator

Aplikasi **static frontend** untuk menghitung estimasi proyek IT dan menghasilkan PDF **Project Estimation** A4. Tampilan PDF mengikuti contoh `Estimasi_Change_Request_Aplikasi_Estimator_29.12.2025.pdf`: header perusahaan, nomor referensi, tabel resource, ringkasan mandays, diskon, grand total, dan area tanda tangan.

- **Tanpa backend** — hanya HTML, CSS, dan JavaScript.
- **Tanpa database** — tidak ada data yang disimpan.
- **Master data JSON** — diedit manual di folder `data/`.
- **PDF dibuat di browser** — tidak ada upload dokumen ke server.

Font aplikasi menggunakan **Arial** (fallback Helvetica/sans-serif). File PDF memakai font standar PDF Helvetica yang metrik dan tampilannya sama dengan Arial, sehingga tidak perlu mengunduh font tambahan.

## Menjalankan

### Lewat WAMP

1. Pastikan folder ini berada di `C:\wamp64\www\EstimateProject`.
2. Jalankan WAMP dan aktifkan Apache.
3. Buka `http://localhost/EstimateProject/`.

### Tanpa WAMP

Jalankan static server dari folder ini, lalu buka alamatnya:

```powershell
php -S 127.0.0.1:8080
```

atau

```powershell
python -m http.server 8080
```

Jangan membuka `index.html` langsung dengan double-click (`file://`), karena browser akan memblokir `fetch` ke file JSON.

## Deploy ke Vercel

Project ini sudah berupa static site, jadi tidak memerlukan build step, server, atau environment variable.

### Lewat dashboard Vercel

1. Upload folder ini ke repository GitHub, atau drag-and-drop foldernya di dashboard Vercel.
2. Import project dengan framework preset **Other**.
3. Biarkan **Build Command** kosong dan **Output Directory** kosong/root.
4. Deploy.

### Lewat Vercel CLI

Dari folder project:

```powershell
npm install -g vercel
vercel
vercel --prod
```

Ikuti prompt dan pilih pengaturan default. Karena tidak ada framework dan tidak ada build, Vercel langsung menyajikan `index.html` beserta folder `data/`, `assets/`, dan `sample/`.

`vercel.json` sudah disertakan untuk:

- `cleanUrls` dan URL tanpa trailing slash.
- `Cache-Control: no-store` untuk `data/*.json`, agar perubahan master data langsung terlihat setelah redeploy.
- Header keamanan dasar.

Setelah mengubah `data/items.json` atau `data/settings.json`, commit dan deploy ulang. File JSON tetap dapat dibaca publik karena memang diambil oleh browser; jangan menyimpan rahasia di sana.

## Cara pakai

1. Isi nomor referensi, tanggal, subject, dan klien.
2. Pilih resource dari master. Rate terisi otomatis; qty dan durasi bisa diubah.
3. Tambah item lain jika perlu, lalu isi diskon.
4. Klik **Download PDF**.
5. File PDF langsung diunduh dari browser.

Tombol **Muat contoh** mengisi data yang sama dengan contoh PDF. Tombol **Reset form** mengosongkan isian. Tidak ada data yang tersimpan; refresh halaman akan menghilangkan semua isian.

## Master data JSON

### `data/items.json`

Daftar resource yang muncul di form:

```json
[
  {
    "id": "fullstack-developer",
    "name": "Fullstack Developer",
    "category": "Engineering",
    "unit": "Day",
    "rate": 280700,
    "active": true
  }
]
```

- `rate` adalah tarif per unit. Untuk resource, isinya tarif per hari; untuk lisensi/software, isinya tarif per qty.
- `active: false` menyembunyikan item dari form tanpa menghapusnya dari file.
- `unit` adalah label satuan (`Day`, `Qty`, `License`, dan sebagainya).
- `duration_required: false` menandai item non-durasi seperti lisensi, software, atau token. Saat item ini dipilih, kolom durasi otomatis menjadi `0` dan subtotal dihitung dari `qty × rate`.
- Durasi juga tetap bisa diisi `0` atau dikosongkan secara manual untuk item apa pun.
- Edit file, simpan, lalu refresh halaman.

### `data/settings.json`

Identitas perusahaan dan format dokumen:

```json
{
  "company_name": "PT. UPSENSE TEKNOLOGI INDONESIA",
  "company_address": "Wisma SMR Lt 9, Unit 904, Kav 89 Jl Yos Sudarso, Sunter Jaya, Jakarta\nUtara, Jakarta, Daerah Khusus Ibukota Jakarta 14350",
  "company_phone": "0852 170000 41",
  "company_email": "sales@upsense.co.id",
  "document_title": "PROJECT ESTIMATION",
  "ref_prefix": "UPSN",
  "ref_start": 470,
  "month_days": 22,
  "signer_title": "Sales & Business Development",
  "footer_text": "Generated by UPSENSE Mandays Estimator",
  "logo": "assets/logo.png"
}
```

- `ref_start` dipakai untuk nomor referensi awal form, misalnya `UPSN/2026/470`.
- `month_days` dipakai untuk konversi durasi hari ke bulan.
- Ganti logo dengan menimpa `assets/logo.png` atau mengubah nilai `logo` ke path lain.

## Rumus

```text
Subtotal item   = durasi > 0 ? rate × qty × durasi : rate × qty
Subtotal        = Σ subtotal item
Total mandays   = Σ (qty × durasi)          # item durasi 0 tidak dihitung
Est. duration   = durasi terpanjang
Total resource  = Σ qty item yang punya durasi (manpower)
Discount        = subtotal × persentase diskon
Grand total     = subtotal - discount
Bulan           = est. duration / month_days
```

Contoh resource:

```text
Fullstack Developer: 1 × 2 hari × Rp 280.700 = Rp 561.400
Discount 25%                                = Rp 140.350
Grand total                                 = Rp 421.050
```

Contoh item tanpa durasi:

```text
OpenAI API Credit: qty 2 × Rp 349.000 = Rp 698.000
```

Item tanpa durasi tetap menambah subtotal dan grand total, tetapi tidak menambah total mandays, est. duration, atau total manpower.

## PDF dan print

- **Download PDF** membuat PDF secara langsung di browser menggunakan layout A4 yang sama dengan preview.
- **Buka PDF** membuka hasilnya di tab baru.
- **Cetak** memakai dialog print browser; pilih *Save as PDF* jika ingin mencetak lewat browser.
- PDF tidak dikirim ke mana pun. Logo dan data JSON dibaca dari origin yang sama.

## Kustomisasi

- Warna brand ada di konfigurasi Tailwind di `index.html` (`brand-50` sampai `brand-950`).
- Layout kertas A4 ada di `assets/app.css` bagian `.paper*`.
- Layout PDF ada di `assets/pdf.js` (`PdfDoc`).
- Teks perusahaan, footer, dan penanda tangan di `data/settings.json`.
- Master rate di `data/items.json`.
- Tailwind disimpan lokal di `assets/vendor/tailwind.js` supaya tidak bergantung pada internet.

## Catatan

- File JSON dapat diakses publik karena memang dibaca oleh browser. Jangan menaruh data rahasia di dalamnya.
- Aplikasi ini tidak memiliki login. Cocok untuk penggunaan lokal atau di balik akses jaringan/internal.
- Browser modern (Chrome, Edge, Firefox, Safari) dengan dukungan `fetch`, `canvas`, dan `Blob` diperlukan.
- Jika data JSON gagal dimuat, pastikan aplikasi dijalankan lewat web server, bukan `file://`, dan file JSON valid.
- Jika logo tidak muncul di PDF, pastikan `assets/logo.png` ada dan dapat dibaca. Generator akan tetap membuat PDF tanpa logo jika gambar gagal dimuat.
